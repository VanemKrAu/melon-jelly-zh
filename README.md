# 🍉 西瓜果冻 · 中文版

一款可抓取、可切割的中文果冻西瓜 **WebGPU** 互动实验。纯浏览器端运行，零依赖、零构建、零后端。

在线体验：**[https://vanemkrau.github.io/melon-jelly-zh/](https://vanemkrau.github.io/melon-jelly-zh/)**

---

## 这是什么

一块半透明的西瓜果冻（带瓜皮的扇形切片），躺在柔和的工作室地板上。你可以用手掌抓起来拉伸、晃动、捏扁，也可以换成切刀在上面划一刀，实时把它切成若干块**各自独立**的软体，每一块都能再抓、再切、再互撞。

页面上同时给出实时读数：质量、体积（静止状态百分比）、动能、块数。

## 交互

| 操作 | 说明 |
|:---|:---|
| **手掌** | 拖动抓取并拉伸果冻；快速点击可弹一下 |
| **切刀** | 在果冻表面划一条线，钢刀落下并沿该平面切开 |
| **配色** | 切换西瓜品种（果皮 / 果肉配色） |
| **硬度** | 低＝颤栗软弹，高＝接近定型 |
| **内部阻尼** | 低＝活泼回弹，高＝糖浆般滞涩 |
| **轻推一下** | 施加一次瞬时冲量，看它抖起来 |
| **粉碎果冻** | 一次性切碎成多块 |
| **¼ 速度** | 放慢物理时间，便于观察细节 |
| **显示网格** | 叠加显示四面体仿真网格 |
| **暂停** | 冻结 / 恢复物理模拟 |

样本可切换：**西瓜切片** / **房子果冻**。

## 技术要点

- **WebGPU + WGSL**，不使用任何图形库；跨浏览器可跑（Chrome / Edge 113+、Safari 26+，Firefox 需开启 `dom.webgpu.enabled`）。
- **软体：四面体 + XPBD**。约 608 个粒子 / 2277 个四面体，固定 60 Hz 步长、每步 10 个子步；每个四面体以有限柔度拉向经过最佳旋转的静止形状（共旋弹性约束），并叠加体积约束使果冻接近不可压缩 —— 所以拉伸时会像真果冻一样收腰。
- **非均质刚度**：瓜皮区域刚度约为果肉的 3 倍；阻尼只作用于网格边上的相对速度，整块果冻仍能自由下落与翻滚。
- **实时切割**：把屏幕轨迹反投影成竖直刀面 → 将每块的当前姿态反解回静止空间 → 在静止平面上做凸多边形切分 → 挤出并重新三角化成新的四面体网格 → 继承父块粒子的位置与速度，并重建西瓜籽 / 气泡的重心坐标绑定。
- **果冻光学**：先渲染地板、籽与气泡，再画背面以估计每条视线穿过果冻的厚度；正面按该厚度折射后方景物，用比尔–朗伯吸收着色，浅色层加乳白散射，薄边背光泛红，菲涅耳反射与 GGX 高光共同构成工作室质感；地面获得染上果冻颜色的柔和主阴影与俯视高度图接触遮挡。
- **随果肉运动的表面**：光滑表面、西瓜籽与气泡都是独立网格，每个顶点通过重心坐标绑定到一个四面体，因此会随周围果肉一起拉伸旋转。

## 本地运行

本项目是 ES module 结构（`index.html` + `styles.css` + `game.js`），直接用 `file://` 打开会被浏览器 CORS 拦截，请起一个静态服务：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080/`。

> 需要支持 **WebGPU** 的浏览器与显卡。若 WebGPU 不可用，页面会显示一张说明性的离线提示卡。
